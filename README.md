🛠️ Technologies Used
This project is built using a standard frontend stack:

HTML5: Used for the core structure and semantic organization of all pages.

CSS3: Custom styles and layouts were applied for design consistency and refinement.

JavaScript (JS): Implemented for interactive elements (e.g., modals, dynamic carousels, and user interactions).

Bootstrap 5: The primary CSS framework used to ensure responsiveness and facilitate rapid, mobile-first UI development.
